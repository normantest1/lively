<objective>
Create backend API endpoints for per-novel statistics and top roles listing.
</objective>

<context>
From bean/beans.py - Database models:
- Novel: id, novel_name, current_state (1=已分片待解析, 2=已解析待合成, 3=已合成语音)
- Role: id, novel_name, role_name, role_count (引用次数), gender, is_bind

Novel.chapter_names is a comma-separated string of chapter names.
</context>

<tasks>

<task type="auto">
  <name>Task 1: Create /api/stats/novels endpoint</name>
  <files>api.py</files>
  <action>
Add GET /api/stats/novels endpoint returning a list of novels with stats:
For each Novel record, compute:
- id: novel.id
- novel_name: novel.novel_name
- chapter_count: number of chapters (split chapter_names by comma, count items)
- role_count: count of Role records where Role.novel_name == novel.novel_name
- current_state: novel.current_state (1/2/3)
- state_name: map {1: "已分片待解析", 2: "已解析待合成", 3: "已合成语音"}

Return JSON: {"novels": [...]} with list of novel stat objects.
</action>
  <verify>
  <automated>curl -s http://localhost:port/api/stats/novels | python -c "import sys,json; d=json.load(sys.stdin); assert 'novels' in d and len(d['novels']) > 0; print('OK')"</automated>
  </verify>
  <done>GET /api/stats/novels returns JSON with array of novels containing id, novel_name, chapter_count, role_count, current_state</done>
</task>

<task type="auto">
  <name>Task 2: Create /api/stats/roles/top endpoint</name>
  <files>api.py</files>
  <action>
Add GET /api/stats/roles/top endpoint accepting query param:
- limit (int, default=50): number of top roles to return

Return top roles ordered by role_count (引用次数) descending:
For each Role, return:
- id: role.id
- role_name: role.role_name
- novel_name: role.novel_name
- role_count: role.role_count
- gender: role.gender
- is_bind: role.is_bind
- presence_rate: role.presence_rate

Return JSON: {"roles": [...]} with top N roles.
</action>
  <verify>
  <automated>curl -s "http://localhost:port/api/stats/roles/top?limit=10" | python -c "import sys,json; d=json.load(sys.stdin); assert 'roles' in d and len(d['roles']) <= 10; print('OK')"</automated>
  </verify>
  <done>GET /api/stats/roles/top returns JSON with array of roles ordered by role_count desc, limited by query param</done>
</task>
